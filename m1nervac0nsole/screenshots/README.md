# Screenshots

`en/` holds the delivered captures of the current UI. They come from the `NEXT_PUBLIC_MOCK=1` demo fixtures, not a live engagement; displayed targets and credentials are fictional. The main README [`../README.md`](../README.md) embeds them.

To regenerate them, start the mock preview (`cd web && NEXT_PUBLIC_MOCK=1 npm run dev`) and capture `/dashboard`, `/function/findings` and a `/chat` session at 1440x1000.
