# Screenshots

This folder holds two separate sets of captures. To keep them from looking mixed, here is what each one is.

- **`en/` — real UI of ARTEX in the default English display language.** This is what the fork delivers. The main README [`../README.md`](../README.md) uses these images. For the delivered screens, open [`en/`](en/).
- **The `*.png` files in the root — upstream (Chinese edition) UI captures.** They are preserved as-is so the fork can be diffed against the upstream repository 1:1. The Chinese README they originally illustrated is no longer shipped in this edition, and no document in this repository references them.
- **`wx.png` — the upstream author's WeChat channel promo image.** Kept alongside the upstream captures. It is unrelated to this fork.

In short, the Chinese screens in the root are kept for upstream preservation; the **delivered English screens live in [`en/`](en/).** See the root README for why this fork keeps the originals alongside (upstream comparison).
